mfp·flow

Shows your account's risk lines on the chart beside the MyFundedPerps terminal. Read-only: this extension never places, changes or cancels an order.

API key

Use a Read Only key. A fp_test_… key reaches sandbox accounts only; a fp_live_… key reaches your real challenge accounts. The key is stored in this browser's extension storage, is never synced to other browsers, and is never given to the page or to the panel — only this background worker reads it.
